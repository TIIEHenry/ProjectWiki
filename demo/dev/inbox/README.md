# 待办收件箱

人类和 Agent 都可记录问题、文档改进或待确认事项。条目按类型放子目录；本例展示 `bug/` 与 `request/`，不要求预建所有空目录。分类名称可按项目调整。

一条一文件，使用不易冲突的短名。正文写观察、推测、来源、核实依据和去向。接受调查不表示已证实，分流为任务不表示已修复。关闭权限遵守项目协作约定。

处理完的条目写明去向（转成的计划、写回的知识、重复的条目或不处理的理由），状态改为"已完成"，再用 `python3 scripts/wiki/wiki.py archive <路径> --root .` 预览、加 `--apply --expect <plan_sha256>` 归档。长期停在"待分诊"的条目会被 `remind` 提醒。

本例的 [组合字符计数疑问](bug/combining-character-count.md) 尚待核实，不能作为既定缺陷引用。
