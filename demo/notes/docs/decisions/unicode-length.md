# 决策：标题按 Unicode 码点计数

状态：采用。范围：标题校验。

## 背景

标题上限需要有可重复的计算方式。“字符”可能指字节、Unicode 码点或用户感知字符，三者不能混用。

## 替代方案

- 按 UTF-8 字节计数：实现简单，但常见中文与英文字母占用的字节数不同，同一上限会给两类标题不同的长度限制，因此不采用。
- 按用户感知字符计数：更接近屏幕显示，但需要额外实现 Unicode 字素边界或引入依赖。第一版只提供标准库本地函数，暂不采用。

## 决定

第一版按 Python 字符串长度计算 Unicode 码点。它不依赖第三方包，常见中文与英文字母使用同一个上限。

## 后果

组合字符与部分 emoji 可能由多个码点构成，计数不等于屏幕上看到的字符个数。这是当前限制，调用方沿用同一计数规则。若以后需要按用户感知字符计数，应评估依赖和兼容性，再修订当前契约。

当前规则在 [模块需求](../requirements.md)；此处只保留取舍与理由，实施进度由计划记录。
