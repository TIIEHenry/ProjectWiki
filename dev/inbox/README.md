# 待处理项

这里接收人类或 Agent 提出的待核实问题、改进请求和研究问题。按类型建立子目录，例如 `bug/`、`doc/`、`debt/`、`question/`、`request/`；有条目时再创建对应目录。

每项使用独立文件和描述性名称，避免协作者反复向一个总表追加。使用[条目模板](../../templates/inbox-item.md)记录来源、观察、推测、核实依据与去向。

接受处理不代表内容已证实，转入计划不代表问题已修复。条目的处理权限沿用接入项目已有协作约定，不按作者类型自行增加新的审批程序。

| 条目 | 内容 |
|---|---|
| [自动归档写入](request/archive-apply.md) | 评估只读预览之后的安全写入能力 |
