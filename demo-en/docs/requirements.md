# Project requirements

Scope: NoteBox. Status: current.

NoteBox needs to validate the title before a note is saved, to keep empty titles and overlong titles out of storage. The first version provides only a local function; storage, a user interface, and an HTTP interface are all out of scope.

The project-level scope is maintained by this page; the specific behavior, the requirement IDs (NB-01, and the candidate NB-02), the acceptance criteria, and the entry to verification are maintained only in the [title module requirements](../notes/docs/requirements.md). The project page does not copy the text of the module requirements.
