# Suggestion to provide a title preview function

Status: open. Source: teaching example, not a real user need.

## Observation

The module currently only returns a valid title or raises an error, and has no preview interface for a user interface to display.

## Suggestion and points to confirm

Callers may need to display the result after whitespace is removed, and its length. Whether a user-interface caller really exists has to be confirmed first; this suggestion cannot be taken directly as a requirement of the first version.

## Basis of verification and where it goes

Not verified yet. Update the project requirements after the scenario is confirmed; create a plan when implementation is needed. Related to the [current scope of the project](../../../docs/requirements.md).
