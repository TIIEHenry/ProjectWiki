# Roadmap

Scope: later direction of NoteBox.

The first phase provides local title validation; for the current capabilities, see the [project requirements](../docs/requirements.md). Next, single-line titles are evaluated first, and then persistence; no delivery date has been promised for either.

| Direction | Dependencies and where it goes |
|---|---|
| Evaluating single-line titles | [Candidate plan](plans/multiline-title.md); compatibility is to be made clear first |
| Persisting notes | Not yet started as a project; the boundary between storage and callers has to be settled first |

Direction and order are maintained here. Implementation steps, execution status, and test results go only in the plan or task concerned and are not copied here.
